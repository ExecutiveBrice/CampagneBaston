# Cartes et plans

La [sélection de cartes pour les huit scénarios](SELECTION.md) regroupe les liens, les alternatives et les conseils de préparation. Chaque zone possède aussi un fichier `Cartes.md` accessible depuis son scénario.

Aucun fichier de carte ou de plan n’est inclus dans l’import initial. Le livret mentionne une carte déjà utilisée dans la préparation ; son image doit être ajoutée séparément.

## Classement proposé à l’ajout des ressources

| Emplacement | Usage |
| --- | --- |
| `carte-generale/` | Carte de référence, original et dimensions d’impression |
| `zones/grande-ville/` | Plans de la ville |
| `zones/village/` | Village et environs |
| `zones/foret/` | Forêt |
| `zones/marecage/` | Marécage |
| `zones/montagne/` | Montagne et col |
| `zones/plaine/` | Plaine |
| `zones/desert/` | Désert et oasis |
| `zones/plage/` | Plage et côte |

Créer ces sous-dossiers au moment de l’import des images. Utiliser des noms explicites comme `village-joueurs.png` et `village-mj.png`. Une variante MJ peut porter les repères et secrets ; la version joueurs évite les révélations. Dans un même dépôt, les deux restent visibles à toute personne disposant de l’accès.

Conserver l’original modifiable lorsqu’il est disponible. Noter l’auteur, le lien de provenance et les conditions de réutilisation connues dans [SOURCES.md](SOURCES.md). Les dimensions et le redimensionnement doivent rester cohérents avec les supports du dossier [indices](../indices/README.md).
