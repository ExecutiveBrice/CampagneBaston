# Histoires générées

Quand cette campagne est ouverte dans NPC, le studio mobile dépose ici les
récits générés à partir d'une idée et les textes soumis à la narration.

Chaque création terminée possède trois fichiers portant le même identifiant :

- `.md` : titre et texte complet, lisibles dans un éditeur ;
- `.wav` : narration audio ;
- `.json` : métadonnées utilisées par la bibliothèque du studio.

Les [voix](../voix/README.md) sont stockées dans le dossier voisin `voix/`.
Les histoires générées sont conservées localement et ignorées par Git.
Elles ne deviennent pas automatiquement des faits de campagne ou du lore PNJ.
