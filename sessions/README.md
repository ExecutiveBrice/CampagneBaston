# Journal des parties

Aucune session jouée n’est consignée pour le moment. Copier [MODELE_SESSION.md](MODELE_SESSION.md) dans un fichier nommé `AAAA-MM-JJ-session-01.md` pour une partie réelle.

Noter les zones choisies, l’ordre des indices remis, les décisions durables, les objets et charges utilisés, l’or du groupe et les promesses faites aux PNJ. Cela permettra de reprendre la partie sans dépendre d’une ancienne conversation.

Utiliser les noms des personnages pour le suivi. Les comptes rendus décrivent cette table et restent distincts du scénario de référence.
